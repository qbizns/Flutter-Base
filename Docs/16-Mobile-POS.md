# Mobile POS
## 📋 Overview
**Location:** `apps/mobile_pos/` | **Status:** ✅ Complete | **Completion:** 75%
## 🎯 Purpose

- Quick order entry with menu shortcuts
- Table assignment and transfer
- Payment processing interface
- Order history and recall
- Modifier management
- Lime theme
